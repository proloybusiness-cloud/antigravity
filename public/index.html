Connect Live Hostinger + Google Drive

  1. Switch Google Drive to Live Mode: Add GOOGLE_SERVICE_ACCOUNT_JSON (or OAuth2 keys) and GOOGLE_DRIVE_FOLDER_ID into your Hostinger .env. The engine switches from local-sandbox to google-drive-live automatically.
  2. Deploy 24/7 on Hostinger VPS: Run docker compose up -d on your Hostinger VPS, or add GitHub Secrets (HOSTINGER_HOST, HOSTINGER_USER, HOSTINGER_SSH_KEY) so pushing to main auto-deploys via .github/workflows/deploy-hostinger.yml.
  3. Control Remotely from Antigravity: Set ANTIGRAVITY_REMOTE_URL and ANTIGRAVITY_API_KEY to manage Core Memory, Drive, and Workflows directly from the CLI.
